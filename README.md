### Реализованные сущности

В рамках лабораторной работы реализована объектная модель музея:

- `Exhibition` — музейная выставка;
- `Tour` — экскурсия;
- `Visitor` — посетитель музея;
- `Ticket` — билет на экскурсию;
- `TourExhibition` — связь между экскурсиями и выставками.

Также реализованы перечисления `ExhibitionTheme` (тематика выставки) и `TicketType` (тип билета).

### Реализованные возможности

- создана доменная модель предметной области;
- подготовлены статические тестовые данные в виде коллекций в памяти;
- добавлено не менее 10 экземпляров каждого класса;
- реализованы LINQ-запросы для обработки данных;
- добавлены unit-тесты с использованием xUnit v3;
- настроена автоматическая проверка тестов через GitHub Actions;
- используется .NET 10.

### Реализованные аналитические запросы

1. Получение топ-5 выставок по количеству уникальных посетителей.
2. Поиск экскурсий с минимальным количеством участников.
3. Получение сводной статистики посещаемости по тематикам выставок за указанный период:
   - общее количество посетителей;
   - общая стоимость билетов;
   - среднее количество посетителей в день;
   - минимальное количество посетителей в день;
   - максимальное количество посетителей в день.
4. Получение всех экскурсий в выбранном зале за заданный период.
5. Получение посетителей выбранной экскурсии с сортировкой по ФИО.
